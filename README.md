# ספר המתכונים של דניאל וישנבצקי

גרסת האתר המלאה הראשונה, שנבנתה מה-Word העדכני.

## מה כבר בפנים
- 1137 רשומות מתכון שחולצו מה-Word.
- 26 קטגוריות בפועל לפי מבנה המסמך.
- 182 מקורות.
- תמונות המתכונים מתוך ה-Word, מומרות ל-WebP כדי להקטין את משקל האתר.
- קטגוריות ותתי-קטגוריות.
- חיפוש וסינון לפי בוצע / Highly Recommended / טרם הוכן.
- עמוד מקורות.
- Modal מלא לכל מתכון.
- תמיכה בסטטוסים: קישור תקין / קישור תקול / ללא קישור.
- שדות מוכנים למצרכים, אופן הכנה וסטטוס שליפה.

## העלאה ל-GitHub Pages
יש להעלות את כל התוכן של התיקייה הזו לשורש ה-Repository:
`index.html`, `styles.css`, `app.js`, התיקיות `data/` ו-`assets/`.

## נתוני המתכונים
נמצאים ב:
`data/recipes.js`

לכל מתכון יש:
- `category`
- `subcategory`
- `title`
- `subtitle`
- `source`
- `url`
- `linkStatus`
- `status`
- `image`
- `ingredients`
- `instructions`
- `extractionStatus`

## סטטוסי שליפה
- `pending` — טרם בוצעה שליפה.
- `success` — נמצאו מצרכים ואופן הכנה.
- `partial` — נמצאו רק חלק מהנתונים.
- `failed` — השליפה נכשלה.
- `no_source` — אין קישור למקור.

## הערה חשובה
הגרסה הזו אינה מבצעת שליפה חיה מתוך Instagram/Facebook בדפדפן. GitHub Pages הוא אתר סטטי, ורשתות חברתיות ואתרים רבים חוסמים גישה כזו מהדפדפן. מנגנון הייבוא האוטומטי יהיה שכבה נפרדת שנוסיף בהמשך.
